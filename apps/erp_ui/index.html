Simulation boundaries

HKM1800-inspired visualization built from original procedural geometry. Not Cognibotics CAD or validated HKM1800 kinematics. Not validated robot dynamics or safety-certified. Not SICS AI proprietary software.

Synthetic observations come from a deterministic observation model; camera images are not analyzed by computer vision. Workspace and collision preflight are conservative simulation logic. Motion timings are presentation timings, not measured robot performance.

Camera controls and replay change only the view. A visible product movement does not prove business completion; verification requires the observation contract.

Where to look in the repository
    
    
    Local files
    The API JSON above is the simplest way to inspect the persisted records. On the desktop, the default data root is %LOCALAPPDATA%\RobotOpsTwin\data. For the CLI, use the directory passed to --data-dir.
    
    
    Workflow events are stored in workflow.db (events table); the controller journal and world configuration are in runtime.db. Custom database names may differ. Blender artifacts are under blender-artifacts. Desktop process logs are under %LOCALAPPDATA%\RobotOpsTwin\sessions; CLI process logs go to its terminal. Inspect a copy of databases; avoid editing a running test.
